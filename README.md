# Agricultural Supply Chain Analytics Dashboard

## Project Overview
An interactive Power BI dashboard for analyzing agricultural production, distributor supply performance, wastage, and retail sales.

## Dashboard Pages

### 1. Farm Production
- Analyzes agricultural production by crop, district, and year.
- Displays total production, total cultivated area, and average yield.
- Uses real agricultural production data.

### 2. Distributor Supply
- Tracks quantities dispatched, received, and wasted.
- Calculates supply efficiency and wastage percentages.
- Uses *synthetic data created for demonstration purposes*.

### 3. Retail Sales
- Analyzes crop sales, revenue, and average selling prices.
- Displays crop-wise sales and sales trends over time.
- Uses *synthetic data created for demonstration purposes*.

## Tools Used
- Microsoft Power BI
- DAX
- CSV datasets
- Data visualization and analytics

## Data Notes
The Farm Production page uses real agricultural data. The Distributor Supply and Retail Sales pages use simulated data and do not represent verified real-world transactions. The source and license of the real agricultural dataset should be acknowledged here.
