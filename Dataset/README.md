# Project Datasets

This folder contains the datasets used in the Agricultural Supply Chain Analytics Dashboard.

- *Farm Production:* Real agricultural production data. Source and license details should be documented.
- *Distributor Supply:* Synthetic data created for demonstration and analysis.
- *Retail Sales:* Synthetic data created for demonstration and analysis.

The Distributor Supply and Retail Sales datasets are simulated and do not represent verified real-world transactions.
